# 制約事項

- オフライン運用は、オンラインで準備を完了した操作画面を開いたままにする方式です。回線断からの新規ログイン、操作画面の再読み込みや OS 再起動後の復元、ブラウザを閉じた状態からの起動には対応していません。OS・ブラウザの保存容量が不足すると準備が失敗します。USB の原本を予備にしてください。短い効果音（20 秒以内）は合計 64 MiB までデコード済みの音声を保持します。残りの音声は再生時にデコードします。
- 投影先の画面への移動と全画面化は Windows とブラウザで手動操作します。OS の出力デバイスが変わった場合は Windows のサウンド設定で選び直します。
- 試聴用出力の列挙・選択ができる環境に限り、ヘッドホンで試聴できます。表示されたデバイスとホテルへの物理接続は運用者が確認します。
- ファイルは最大 50 MB です。ファイル形式はブラウザでヘッダーとデコードを確認し、サーバー側は MIME・容量・パス・権限を制限します。サーバー側での内容の再デコード・ウイルス検査はありません。アップロードは TUS の通信再試行に対応し、画面を閉じた後からの中断位置復元は対象外です。
- 一覧はメタデータ編集に対応します。既存ファイルを同じカードで置換する機能と、未使用オブジェクトの自動回収はありません。取消済みアカウントの再付与は Dashboard 管理者が行います。
- 本番中の素材は固定され、端末への事前コピーは共有側の削除や権限取り消し時にも既に準備したセッション中は保持されます。終了操作で端末キャッシュを削除します。異常終了で残った場合は本番後、当サイトのブラウザデータを消去してください。
- ダッキングは素材の設定と再生状態で判定します。動画に含まれる無音区間を音圧で検出する機能はありません。
