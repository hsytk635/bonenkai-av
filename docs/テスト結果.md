# 動作確認結果

実施日 2026年11月27日。Windows の Chrome 158.0.8127.88 と Edge 158.0.4370.33 をヘッドレスで使用しました。音と映像は試験中に合成し、第三者の作品は使用していません。

| 検証 | 結果 |
| --- | --- |
| TypeScript 型検査、Vite 本番ビルド | 合格 |
| SQL マイグレーション | ローカル PostgreSQL（PGlite）で適用成功。Supabase の auth / storage スキーマはテスト用の定義 |
| ロール別の DB と Storage 制御 | 未認証拒否、閲覧者の書込み拒否、編集者の登録・編集・削除、参照中ファイルの削除拒否、管理者による権限変更・取消を確認 |
| 操作画面と別ウィンドウ | 接続、Fullscreen API、画像投影、黒画面、切断警告、再接続を Chrome・Edge で確認 |
| 音響 | BGM 再生・一時停止・再開、複数効果音の重ね再生、ダッキングの低減・復帰、全音声停止を確認 |
| 動画音声 | MP4・WebM を投影し、同じ動画の音声が動画バスに届くことを波形で確認。音声を止めながら動画を継続できることも確認 |
| 映像素材 | MP4・WebM の再生、一時停止、頭出し、ループ、終了後の待機画面とサムネイル生成を確認。PNG・JPEG・WebP の読み込みとサムネイル生成を確認 |
| 素材プレビュー | 試聴の初期状態が消音で、投影画像が変化しないことを確認。ヘッドホンの物理的な出力先は未検証 |
| 回線断の模擬 | ブラウザのネットワークを無効にし、固定済みの音声・画像・MP4・WebM を再生。回線断中の投影ウィンドウ再接続も確認 |
| 入力エラー | 内容が画像形式と一致しない PNG を拒否 |

## 実環境での受入確認

- Supabase の実プロジェクトで、招待メールとパスワード設定、三権限でのログイン、TUS 転送途中の復旧、署名付き URL、複数端末間での反映を確認する必要があります。
- GitHub Pages への初回デプロイと公開 URL での認証リダイレクトは未実施です。
- ホテルのプロジェクターと音響ミキサーへの接続、映像と音の同期の視聴、音声の二重出力有無、長時間運転、本番 PC の物理的な回線断と全素材の再生は未実施です。[本番チェックリスト](本番チェックリスト.md) に沿って確認してください。

## 自動確認を再実行する場合

リポジトリルートで依存関係をインストールし、次を実行します。ブラウザテストは Windows のローカルアドレスで一時サーバーを起動するため、ループバック接続が可能な環境を使います。Supabase 未設定の動作確認モードが対象です。

```powershell
npm ci
npm run build
npm install --prefix node_modules/.qa playwright-core @electric-sql/pglite
node tests/policies.mjs
node tests/browser.mjs
node tests/browser.mjs 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
```
