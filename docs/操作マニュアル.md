# 操作マニュアル

## 素材の登録と確認

1. 招待メールを開いてパスワードを設定し、ログインします。
2. 管理者・編集者は「共有設定」でカテゴリを作成できます。「メディア登録」から種別とファイルを選び、色、音量、ループ、フェード、ダッキング対象などを設定します。一覧の「編集」で登録情報を変更できます。
3. 「確認」を押すと操作画面内でプレビューできます。動画は初期状態で消音します。試聴は、Windows で会場送りと別になっている出力を確認し、専用ヘッドホンを選べるときだけ行います。出力先が表示されない場合は、消音のまま確認するか、事前に会場送りを外して本番ボタンで試聴してください。
4. 「削除」を押すと確認が表示されます。メタデータ削除後のファイル整理でエラーが出た場合は Dashboard の Storage で該当 UUID フォルダを調べ、`media.storage_path` と `media.thumbnail_path` から参照されていないことを確認してから該当オブジェクトを整理します。SQL で Storage のオブジェクト行だけを削除すると実体が残るため、Dashboard の Storage を使ってください。

## 開演前

1. Windows PC とプロジェクターを HDMI 等で接続し、**Windows + P → 拡張** を選びます。
2. Chrome または Edge でログインし、「音声を有効化」を押します。「映像出力画面を開く」を押し、黒い別ウィンドウをプロジェクター側にドラッグします。**Windows + Shift + 左／右矢印** でも隣のディスプレイへ移動できます。
3. 投影側の「全画面にする」を押します。ボタンは全画面中に消えます。移動し直す場合は **Esc** で全画面を解除します。動画開始が拒否された場合は投影画面をクリックし、操作画面で再試行します。
4. Windows 設定 → システム → サウンド → 出力で、ホテルのミキサーにつながる端子または USB インターフェースを選びます。HDMI 接続直後は出力先の切り替わりを確認します。ホテル側でチャンネルを開け、PC のマスターを低めから上げてレベルを合わせます。
5. 「事前読み込み・本番モード開始」を押します。全件準備済みになるまで待ち、[本番チェックリスト](本番チェックリスト.md) を実施します。本番中は操作画面を開いたままにし、ブラウザの再読み込みと PC のスリープを避けます。

## 本番中

- 大きな素材ボタンで本番出力します。BGM は切り替え式です。登場曲と効果音は BGM と重ねられます。動画を押すと投影用ウィンドウで映像と音声を同時再生します。
- ミキサーで BGM、登場曲、効果音、動画、マスターを調整できます。「ダッキング ON／OFF」で本番中の有効状態を変えます。設定が有効な素材の再生が重なると、すべて終了してから BGM が元へ戻ります。
- 映像モニターで一時停止・再開、頭出し、再生位置の変更ができます。「待機画面」で設定済み素材、またはイベントタイトルを投影します。
- 「全音声停止」は投影を維持して音声を止めます。消音された動画の音声は同じ動画の素材ボタンを押して再開できます。「映像停止」と「黒画面」は投影だけを止めます。「全停止」は両方を止めます。
- 映像が映って音が出ない場合は、音声有効状態、マスター、動画レベル、Windows の出力先、ホテル側の入力・ミュートを順に確認します。動画に音声があるかも確認してください。
- 投影が切断された場合は「映像出力画面を開く」で開き直し、ディスプレイ移動と全画面をやり直します。対象素材をもう一度選択します。

Chrome の再生許可については [Chrome Developers の自動再生ポリシー](https://developer.chrome.com/blog/autoplay) を参照してください。
